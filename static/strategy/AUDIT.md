## 結論

**AIで手間を減らし、つくる・遊ぶ・会う時間を増やす。**

事業を説明する順番は「技術の一覧」より「今日やりたいこと → 最初の一歩 → 得られる体験」が適切だと判断しました。これは今回の調査からの戦略提案です。利用率向上が測定済みという意味ではありません。

1. 手間を減らす：teai / Sente。
2. 想いを形にする：KOE / MU / kamishibai.tv / movie.live。
3. 体験を分かち合う：JiuFlow / uta.live / SOLUNA / enabler.fun。

ブランドの役割を示す図であり、全サービス共通アカウント・共通課金・自動連携の完成を表すものではありません。

## 戦略の判断と測り方

1. **最初の一回が完了すること**を優先。表示できた率ではなく「本人が役立ったと確認した成果」、商品が届いた事実、声が登録後に使えた事実で判定。
2. **実装を同時に広げすぎない**。既存方針の同時2本を守り、今回はMUとutaの確定不具合から対応。
3. **継続・実需・採算で焦点を絞る**。9サービスへ均等に広告や実装費を配分しない。まず一市場・具体的な利用者を優先。
4. 自社内の生成数や自社間流通だけを成功にしない。外部利用者の初回完了、7日再訪、実決済、原価控除後の粗利益、未解決の問い合わせを見る。
5. 関連サービスへの利用は需要のある場面から。JiuFlow→MUは道場の一着、滞在→utaは仲間との歌、teai→KOE→紙芝居は説明や贈り物という仮説を検証する。
