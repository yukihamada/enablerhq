quickstart.py
from openai import OpenAI

client = OpenAI(
  base_url="https://api.teai.io/v1",
  api_key="te_your_api_key",
)

resp = client.chat.completions.create(
  model="claude-sonnet-4-6",  # or gpt-4o, gemini-2.5-pro, deepseek-v3
  messages=[{"role": "user", "content": "Hello!"}],
)

print(resp.choices[0].message.content)

FEATURES
土台がやること

OpenAI SDK をそのまま使える互換 API。base_url を変えるだけで、下にあるどのモデル会社にも届く。速さ・切替・請求は土台が引き受ける。

東京サーバー

東京リージョン(ap-northeast-1)からAPIをプロキシ。ゲートウェイ自体の応答は実測で約0.2秒、モデル別の推論レイテンシ(TTFT/E2E)は /api/v1/latency で常時公開。国内からのアクセスに最適化。

自動フォールバック

プロバイダー障害時に自動で別モデルに切替。GPT-4oが落ちたらClaude、ClaudeがダメならGemini。ダウンタイムゼロ。

公開建値より安い自動値付け

市場の公開建値を6時間ごとに取り込み、主要モデルを建値より約2%安い単価に自動設定。単価も実測速度もAPIで全公開。

日本語サポート

ドキュメント、ダッシュボード、サポート全て日本語対応。請求書払い・インボイス対応で法人利用も安心。

日本法人の安心 — 請求書・インボイス・SLA

円建て・適格請求書（インボイス）・見積書・SLA 99.9%保証。海外ゲートウェイが真似できない、経理・調達が通せる唯一の日本法人。 OpenRouterとの違い →

ストリーミング SSE

全モデルでServer-Sent Events対応。チャットUIもエージェントも、リアルタイム応答を即座に表示。

BYOK対応予定

自分のAPIキーを持ち込み可能（対応予定）。データがteai.ioを経由しない直接モードを企業向けに整備中。

本人声TTS「Koe」

海外APIに無い、日本語・本人声の音声合成。model:"koe" を /v1/audio/speech に渡すだけ。声の登録・クローンは koe.live →
